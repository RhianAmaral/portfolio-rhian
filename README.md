# Portfólio — Rhian Amaral

Este portfólio apresenta um pouco da minha trajetória, minhas tecnologias e alguns dos projetos que desenvolvi. Foi criado com React e TypeScript, usando Tailwind CSS para os estilos e Framer Motion para as animações.

## Executar localmente

Com o Node.js instalado, execute:

```bash
npm install
npm run dev
```

Depois, acesse `http://localhost:5173`.

Para gerar e visualizar a versão de produção:

```bash
npm run build
npm run preview
```

As animações respeitam a preferência `prefers-reduced-motion` do dispositivo.
